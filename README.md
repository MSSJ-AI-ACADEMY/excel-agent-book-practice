# 《클로드로 엑셀 천재되기》 실습 자료

책 《클로드로 엑셀 천재되기》를 읽으며 **직접 따라 해 볼 엑셀 파일**, 장마다 혼자 해 볼 **과제 60개**, 해 본 결과가 맞는지 알려 주는 **채점기**가 들어 있습니다.

책은 엑셀에게 일을 «시키는 법»보다 시킨 결과를 «확인하는 법»을 더 많이 다룹니다. 이 저장소도 같습니다.
「다 했습니다」라는 답 대신, 파일을 직접 열어 맞았는지 확인하는 연습을 합니다.

## 1. 한눈에 보기

| 권 | 부 | 장 | 과제 |
|---|---|---|---|
| 1권 「엑셀에 AI 연결하기」 | 0부 준비 | 0~2장 | 장마다 2개 + 종합 1개 |
| 1권 「엑셀에 AI 연결하기」 | 1부 화면부터 만지기 | 3~4장 | 장마다 2개 + 종합 1개 |
| 1권 「엑셀에 AI 연결하기」 | 2부 쓰던 파일 살리기 | 5~8장 | 장마다 2개 + 종합 1개 |
| 1권 「엑셀에 AI 연결하기」 | 3부 수식 열기 | 9~11장 | 장마다 2개 + 종합 1개 |
| 2권 「AI로 엑셀 완벽히 자동화하기」 | 4부 매크로와 VBA | 12~15장 | 장마다 2개 + 종합 1개 |
| 2권 「AI로 엑셀 완벽히 자동화하기」 | 5부 내 자산 되살리기 | 16~18장 | 장마다 2개 + 종합 1개 |

- **practice** 폴더: 책 본문이 부르는 실습 엑셀 파일(원본). 고치지 않고 늘 사본으로 합니다.
- **exercises** 폴더: 과제 하나 = 폴더 하나. `README.md` 한 장만 읽으면 과제를 할 수 있습니다.
- **grader** 폴더: 채점기. 과제를 끝낸 파일을 넣으면 항목마다 맞았는지 알려 줍니다.

## 2. 처음 오셨다면: 이 순서대로

1. **책 1권 「처음 실행하는 날」을 먼저 봅니다.** 클로드 코드를 깔고, 까만 창(터미널)에서 첫 심부름을 시켜 보는 절입니다. 이 저장소의 과제는 그 준비가 끝난 뒤를 기준으로 짜여 있습니다.
2. **이 저장소를 받습니다.** 아래 「3. 받는 법」의 ① 압축 파일이 가장 쉽습니다.
3. **실습 폴더를 만듭니다.** 책이 부르는 이름은 `C:\엑셀실습` 입니다(띄어쓰기 없이). 받은 저장소의 `practice` 폴더 안 파일을 이 폴더로 **복사**합니다.
4. **책을 한 장 읽고, 그 장의 과제를 합니다.** 아래 「5. 권·장별 실습 지도」에서 장 번호를 찾아 과제 링크를 누르면 됩니다.
5. **채점합니다.** 자동 채점 과제는 채점기에 파일을 넣고(「8. 채점기」), 스스로 확인하는 과제는 확인 목록을 하나씩 체크합니다.

준비물: 윈도우 PC와 엑셀, 클로드 유료 요금제(Pro 이상). 채점기를 쓰려면 파이썬도 필요합니다(「8. 채점기」에 설치 안내).

## 3. 받는 법

**① 압축 파일로 받기 (처음이라면 이쪽)**

1. 이 페이지 위쪽의 초록색 **Code** 버튼을 누릅니다.
2. 맨 아래 **Download ZIP** 을 누릅니다.
3. 내려받은 파일을 오른쪽 클릭해 **압축 풀기**를 합니다.
4. 풀고 나면 이름 끝에 `-main` 이 붙은 폴더(`excel-agent-book-practice-main`)가 생깁니다. 이 폴더를 이 안내에서는 「저장소 폴더」라고 부릅니다.
   그 폴더를 열었을 때 `practice` · `exercises` · `grader` 세 폴더와 이 `README.md` 가 바로 보여야 합니다. 폴더를 한 번 더 열어야 보인다면, 한 겹 안쪽 폴더가 저장소 폴더입니다.

**② git 으로 받기 (git 을 써 봤다면)**

```
git clone https://github.com/MSSJ-AI-ACADEMY/excel-agent-book-practice.git
```

## 4. 한 장을 실습하는 순서

과제 문서(`exercises/<번호>/README.md`)는 모두 같은 차례로 쓰여 있습니다. 위에서부터 읽으며 따라가면 됩니다.

| 과제 문서의 칸 | 무엇을 하나 |
|---|---|
| 어느 장 | 이 과제가 다시 써 보게 하는 책의 절. **그 절을 먼저 읽고 옵니다** |
| 시작 파일 | practice 의 어느 파일에서 시작하는지. **원본은 열지 말고 사본을 만들어** 시작합니다 |
| 낼 파일 | 채점기에 넣을 파일 이름. 이름을 그대로 맞춥니다 |
| 왜 하나 | 이 과제가 책의 어느 확인법을 연습하는지 |
| 할 일 | 순서대로 번호가 붙어 있습니다. 회색 상자 안 문장은 클로드 코드에 그대로 칠 **시킬 말**입니다. 책에 나온 말은 책 그대로, 과제에서 새로 붙인 말은 ‹› 로 표시했습니다 |
| 확인법 | 그 장에서 배운 확인 문장. 답을 받은 뒤 이 기준으로 봅니다 |
| 채점 | 자동 채점(auto)이면 채점 명령, 스스로 확인(manual)이면 확인 목록 |

막히면 과제 폴더의 `solution/` (정답 예시)과 `wrong/` (흔한 실수 예시)를 엽니다. 정답을 먼저 보기보다, 내 파일과 무엇이 다른지 비교하는 데 쓰세요.

## 8. 채점기

채점기는 파이썬(Python, 프로그램을 돌리는 도구)으로 돕니다.

**명령 창을 저장소 폴더에서 여는 법.** 파일 탐색기로 저장소 폴더(`README.md` 가 보이는 폴더)를 엽니다.
위쪽 주소 표시줄을 한 번 누르고, 거기 적힌 경로를 지운 뒤 `cmd` 라고 치고 엔터를 누릅니다.
검은 창이 뜨고 맨 앞에 그 폴더 경로가 보이면 됩니다. 아래 명령은 모두 이 창에 칩니다.

먼저 이 한 줄을 쳐 보세요.

```
python --version
```

`Python 3.9` 이상이 나오면 됩니다. 다음 둘 중 하나라면 파이썬이 아직 없는 것입니다.

- 「'python'은(는) 내부 또는 외부 명령 … 이 아닙니다」 같은 글이 나온다
- 아무 글 없이 마이크로소프트 스토어(Microsoft Store) 창이 뜬다

그때는 `python.org` 의 Downloads 에서 파이썬을 내려받아 설치합니다.
설치 첫 화면 아래쪽의 **「Add python.exe to PATH」 칸에 꼭 체크**하고 설치하세요. 이 칸을 빼먹으면 설치하고도 위와 같은 글이 나옵니다.
설치가 끝나면 명령 창을 **닫았다가 다시 열고** `python --version` 을 한 번 더 쳐 봅니다.

그다음 엑셀 파일을 읽는 부품(openpyxl)을 한 번만 설치합니다.

```
python -m pip install openpyxl
```


저장소 폴더(이 README 가 있는 폴더)에서 이렇게 칩니다.

```
python grader/check.py <과제번호> <내 파일>
```

예를 들어 첫 과제를 끝내고 `00-01_점검.xlsx` 를 만들었다면:

```
python grader/check.py 00-01 00-01_점검.xlsx
```

파일 이름에 띄어쓰기가 있으면 이름 전체를 큰따옴표로 감쌉니다. 따옴표가 없으면 채점기가 이름을 둘로 알아듣습니다.

```
python grader/check.py 08-01 "부서 관리대장_20260921.xlsx"
```

결과는 항목마다 한 줄씩 나옵니다.

| 표시 | 뜻 |
|---|---|
| ✓ | 맞았습니다 |
| ✗ | 틀렸습니다. 바로 아래 줄에 왜 틀렸는지가 나옵니다 |
| ! | 채점할 수 없습니다. 수식은 있는데 계산된 값이 파일에 없습니다 — **엑셀에서 그 파일을 한 번 열고 저장한 뒤** 다시 채점하세요 |
| ? | 과제 쪽 규칙에 문제가 있습니다. 저장소를 최신으로 다시 받아 보세요 |

`!` 가 나오는 이유: 클로드가 파이썬으로 파일을 저장하면 수식은 들어가도 **계산 결과는 비어 있는 채로** 저장됩니다(책 24.2·25.1).
엑셀로 한 번 열고 저장하면 엑셀이 계산해서 채워 넣습니다. 틀린 것이 아니라 아직 계산이 안 된 것이라 ✗ 로 적지 않습니다.

채점기는 기대값을 되도록 과제 문서에 적어 두지 않고, **practice 폴더의 원본 자료에서 직접 계산**합니다.
예를 들어 「금액 합계」를 볼 때는 원본의 수량과 단가를 행마다 곱해서 더한 값과 댑니다.
정렬 순서처럼 채점기가 아직 계산하지 못하는 것은 숫자를 check.json 에 적어 두었습니다. 그런 과제에는
`_expected.py` 가 있어서, 적어 둔 숫자가 원본에서 따로 계산한 값과 같은지 누구나 돌려 볼 수 있습니다.

스스로 확인하는 과제(manual)는 파일 없이 번호만 치면 확인 목록이 나옵니다.

```
python grader/check.py 00-02
```

| `?` 가 나온다 | 과제 쪽 규칙 문제입니다. 저장소를 최신으로 다시 받아 봅니다 |
| 클로드 코드가 실습 폴더 밖 파일을 본다 | 클로드 코드는 실행할 때 들어가 있던 폴더를 기준으로 일합니다. `C:\엑셀실습` 에서 실행했는지 줄 맨 앞의 경로를 확인합니다(책 「처음 실행하는 날」) |

## 10. 채점기가 제대로 도는지 테스트하기 (선택)

채점기를 수정하거나 과제를 더하는 분만 보면 됩니다.

```
python -m pip install pytest
python -m pytest grader
```

정답 파일은 전부 ✓, 오답 파일은 일부러 틀리게 만든 그 항목만 ✗, 계산값이 없는 파일은 ✗ 가 아니라 ! 가 나오는지를 봅니다.
자동 채점 과제 51개도 모두 돌립니다. 과제마다 `solution/` 의 정답 예시는 전부 ✓, `wrong/` 의 오답 예시는 그 과제의 `_verify.txt` 에 적힌 항목만 ✗ 인지 확인합니다.
